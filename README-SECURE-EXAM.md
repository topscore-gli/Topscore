# TopScore secure online examination implementation

## What changed

- The five existing CBT question banks were extracted from the public HTML and are now expected through the private Firebase Secret Manager secret `TOPSCORE_QUESTION_BANK_JSON` (61 English, 40 Mathematics, 40 Biology, 40 Chemistry and 40 Physics source questions). The private JSON is supplied separately from the public project ZIP and must never be committed to the GitHub Pages repository.
- `startOnlineExam` creates one server-controlled session per student and exam, selects/shuffles the 180-question paper, and returns question text/options without correct answers or explanations.
- The server stores the answer key and question set in `examSessions`. Firestore rules explicitly deny all client reads and writes to this collection.
- The session deadline is generated by the server from the exam duration. The browser countdown is only a display; `submitOnlineExam` checks the server deadline.
- `submitOnlineExam` accepts option selections, validates question IDs and option indexes against the server's paper, calculates the score on the server, and writes one verified result. A legacy unverified result for that student/exam can be replaced after they complete the secure attempt. The result is marked `verifiedByServer: true`.
- Official exam leaderboards now filter for `verifiedByServer: true`, so old client-trusted scores are excluded from official rankings.
- The old `recordOnlineExamResult` endpoint now rejects client-calculated scores.
- The active CBT page now loads its questions from the secure callable functions and displays the server-returned result. The old `jambexam1.html` and `jambex.html` copies redirect to the secure page so their embedded answer keys are no longer published in those copies.

## Important limitations / release steps

1. Before deploying, create the private Secret Manager secret from the separate `TopScore-Question-Bank-Private.json` file. For a new secret, run:

   ```bash
   gcloud secrets create TOPSCORE_QUESTION_BANK_JSON --replication-policy=automatic --project=jamb-b6a95
   gcloud secrets versions add TOPSCORE_QUESTION_BANK_JSON --data-file=TopScore-Question-Bank-Private.json --project=jamb-b6a95
   ```

   If the secret already exists, skip the create command and add a new version. Keep the JSON file outside the GitHub Pages project and do not commit or upload it publicly. The Cloud Functions `startOnlineExam` and `submitOnlineExam` bind this secret.

2. This is a source-code implementation. It has **not** been deployed to Firebase, tested against the Firebase Emulator, or exercised with a real student account. Do not treat it as live until those tests pass.
3. Deploy the updated Firestore rules and Cloud Functions together. The secure page requires the new `startOnlineExam` and `submitOnlineExam` callable functions.
4. Existing historical `onlineExamResults` may have been created by the old client-trusted endpoint. They are not automatically verified by this change; review/quarantine legacy rows before using the leaderboard for prizes or official rankings.
5. The server-side question bank currently covers English, Mathematics, Biology, Chemistry and Physics. The CBT now uses the student's saved four-subject JAMB combination (Use of English plus three selected subjects) when all three electives are supported. The paper contains 60 English questions and 40 questions for each selected elective (180 total). If a student selected an unsupported subject such as Government, Economics, Literature in English, Commerce, Accounting, Geography or Agricultural Science, the server rejects entry before deducting the 500 points and explains that the subject bank is not yet available. Add and academically review those banks before enabling those combinations.
6. Answers sync to the server every 30 seconds. A candidate may still lose the most recent changes made after the last successful sync if connectivity is lost or the browser closes abruptly. A high-stakes deployment should consider more frequent answer syncing and a clear sync-status indicator.
7. The current content itself needs academic review. Some legacy questions refer to placeholder image URLs and the bank is a compact practice bank, not a complete official JAMB question archive.
8. The submission and autosave endpoints allow a 30-second network grace after the server deadline so a request sent at the end of the timer can arrive. It does not extend the displayed exam time.

## Recommended validation before deployment

- Run Firebase Emulator tests for premium checks, point deduction, session creation, repeat joins, expiry, invalid question IDs, invalid answer indexes, duplicate submissions, and result leaderboard visibility.
- Confirm that an authenticated client cannot read `examSessions` through Firestore SDK or REST.
- Test a 120-minute session, refresh/reopen recovery, manual submission, timeout submission, and network loss on Android and desktop.
- Verify that no public HTML/JS file contains the correct-answer bank after publishing the repository.
- Decide how to archive or label old unverified results before enabling leaderboard rewards.


## 2026-11-07 continuation: profile-based subject combinations

- The online exam now reads the student's saved JAMB subject combination from their profile instead of hardcoding Mathematics, Chemistry and Physics for every candidate.
- Use of English remains compulsory (60 questions); each of the three selected electives receives 40 questions, for 180 total.
- The currently available banks are English, Mathematics, Biology, Chemistry and Physics. Other subjects remain unavailable until their question banks are authored and reviewed.
- `joinExam` validates the full subject combination before deducting the 500-point entry fee. Unsupported combinations are rejected with a clear message and no point deduction.
- The online exam listing now shows the student's saved subject combination.

## 2026-11-07 continuation: student subject editor

- The Account page now lets a student update their JAMB subject combination after registration. Use of English is fixed as compulsory and the student must select exactly three electives.
- The editor lists the full subject choices already accepted by the student-profile function. It clearly distinguishes the five currently banked CBT subjects from subjects whose banks are still being prepared.
- Saving uses the authenticated `createProfile` callable; the page does not write profile data directly to Firestore.
- Selecting unsupported electives is allowed for profile/course planning, but the secure CBT will not deduct entry points or start an exam until all three selected electives have supported question banks.

## 2026-11-07 continuation: offline question-bank manager

- Added `question-bank-manager.html`, a browser-local editor for importing, adding, editing, deleting, searching and exporting the private question-bank JSON.
- The tool validates required question text, 2–6 non-empty options, correct-answer indexes, optional explanation/image fields, and duplicate question text. It reports bank counts against the current paper requirements (60 English; 40 per elective).
- It includes all 18 subject bank keys currently accepted by the student profile editor, but this does **not** automatically enable new subjects in the live CBT backend.
- The manager makes no network requests and does not connect to Firebase. Exported JSON must remain private and be uploaded only to Firebase Secret Manager. Structural validation is not academic review.
