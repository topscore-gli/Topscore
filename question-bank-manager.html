Publishing checklist

  1. Review every question, option, correct answer and explanation with a qualified subject teacher.
  2. Confirm image links are durable and do not expose answer information.
  3. Export the private JSON and keep a secure backup.
  4. Upload it to Firebase Secret Manager as TOPSCORE_QUESTION_BANK_JSON; never commit it to GitHub Pages.
  5. Deploy and test the Cloud Functions with Firebase Emulator before a live release.
  6. Only enable a subject for exam entry after its bank meets the required count and has passed academic review.
